# Project Euler

A small selection of [Project Euler](https://projecteuler.net) problems I solved in C++.
Each folder has its own README with the approach.

| Problem | Task | Approach |
|---|---|---|
| [59 – XOR Decryption](59_XOR_Decryption) | Find a 3-letter XOR key and decrypt a text | Brute force over all 17 576 keys, scored by the share of letters |
| [206 – Concealed Square](206_Concealed_Square) | Find the number whose square has the form `1_2_3_4_5_6_7_8_9_0` | Narrowed bounds, only multiples of 10, early digit check |
