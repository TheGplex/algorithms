# Algorithms

A collection of smaller programs in C and C++ that I wrote to try out ideas and practise problem solving. Each folder has its own README.

| Project | Language | Description |
|---|---|---|
| [Truth Table](truth-table) | C | Computes the truth table of a logic expression with four inputs |
| [Project Euler](project-euler) | C++ | Selected Project Euler problems, with the approach explained |
| [Word Similarity](word-similarity) | C++ | Similarity of groceries as 2D vectors, the basic idea behind word embeddings |

All projects build with a single compiler call; see the README in each folder.
